# Навык Алисы с Gemini на Vercel

Минимальный serverless-проект: webhook Яндекс Диалогов → Gemini API → ответ Алисе. Без базы данных и дополнительных npm-зависимостей. История последних четырёх обменов хранится в `session_state` навыка. Vercel автоматически обнаруживает Node.js Functions в каталоге `api/`; минимальный `vercel.json` не переопределяет стандартные маршруты.

## Что понадобится

- аккаунт Google AI Studio и Gemini API key: https://aistudio.google.com/apikey
- аккаунт GitHub
- аккаунт Vercel: https://vercel.com/
- доступ к консоли Яндекс Диалогов: https://dialogs.yandex.ru/development

## Развёртывание на Vercel

1. Создай пустой репозиторий GitHub и загрузи в него все файлы этого проекта.
2. В Vercel выбери **Add New → Project**, импортируй репозиторий. В репозитории на верхнем уровне должны лежать `package.json`, `vercel.json` и папка `api/` с двумя JS-файлами (не загружай ZIP как единственный файл). Если раньше Vercel пытался запустить Python, открой **Settings → General → Build & Development Settings**: Framework Preset выбери **Other**, Root Directory укажи папку, где лежат `package.json` и `vercel.json`, а Python-specific build/output overrides удали. Затем сделай новый deploy.
3. В настройках проекта Vercel открой **Settings → Environment Variables**. В Framework Preset выбери **Other**, а Root Directory оставь папкой с `package.json`, `vercel.json` и `api/`. Добавь переменные:
   - `GEMINI_API_KEY` — ключ из Google AI Studio (обязателен).
   - `GEMINI_MODEL` — необязательно; по умолчанию `gemini-3.5-flash-lite`.
   - `ALICE_SKILL_ID` — пока не добавляй на этапе первичной настройки. Включи его позже, когда проверишь точное значение `session.skill_id` в запросе Алисы.
4. После добавления `GEMINI_API_KEY` сделай redeploy (новый deployment), чтобы переменные применились.
5. Проверь `https://ТВОЙ-ПРОЕКТ.vercel.app/api/health`. Должен прийти JSON `{"ok":true,"service":"alice-gemini-skill"}`. При открытии `/api/alice` через браузер методом GET ожидается JSON с ошибкой 405 — это нормально, так как Алиса обращается POST-запросом.

## Подключение навыка в Яндекс Диалогах

1. Создай навык в консоли разработчика Яндекс Диалогов.
2. В настройке Backend выбери **Webhook URL** и укажи `https://ТВОЙ-ПРОЕКТ.vercel.app/api/alice`.
3. Укажи webhook именно `https://ТВОЙ-ПРОЕКТ.vercel.app/api/alice` (не только домен без `/api/alice`). Сохрани настройки и перейди во вкладку тестирования. Отправь фразы вроде «Привет», «Объясни, что такое нейросеть простыми словами» и «Помнишь, о чём мы говорили?».
4. После создания навыка скопируй его `skill_id` из сведений о навыке. В Vercel добавь переменную `ALICE_SKILL_ID` с этим точным значением и сделай redeploy. Тогда endpoint будет отклонять запросы с другим `skill_id`.

## Локальная проверка

Нужен Node.js 20 или новее.

```bash
npm run check
```

Проверка доступности после deploy:

```bash
curl https://ТВОЙ-ПРОЕКТ.vercel.app/api/health
```

Webhook можно проверить примерным запросом из консоли Диалогов. Для прямого теста замени `skill_id` на фактический ID навыка, если включил `ALICE_SKILL_ID`:

```bash
curl -X POST 'https://ТВОЙ-ПРОЕКТ.vercel.app/api/alice' \
  -H 'Content-Type: application/json' \
  -d '{
    "meta": {"locale":"ru-RU"},
    "request": {"type":"SimpleUtterance","command":"Объясни квантовую физику простыми словами","original_utterance":"Объясни квантовую физику простыми словами"},
    "session": {"new":true,"message_id":0,"session_id":"test-session","skill_id":"YOUR_SKILL_ID"},
    "state": {"session":{}},
    "version":"1.0"
  }'
```

## Важные нюансы

- **Лимит Яндекс Диалогов — 4,5 секунды на весь webhook.** Вызов Gemini ограничен 2,5 секунды, чтобы оставить время на сеть и ответ Алисе. Простые приветствия обрабатываются локально без вызова модели. Если Gemini или холодный старт Vercel задержится, навык вернёт дружелюбное сообщение с просьбой повторить вопрос. Это ограничение платформы, а не гарантия скорости модели.
- Квоты Gemini API зависят от модели, проекта и текущих условий аккаунта; бесплатный доступ не означает безлимитное использование. Посмотри действующие квоты в Google AI Studio.
- В Vercel Hobby соблюдай условия бесплатного тарифа. Ключ Gemini хранится только в server-side Environment Variables — не добавляй его в код или публичный репозиторий.
- `ALICE_SKILL_ID` — дополнительная базовая защита от случайного/постороннего использования публичного webhook; это не полноценная криптографическая авторизация. Для первого запуска оставь её выключенной, чтобы исключить несовпадение ID навыка.
- История диалога хранится в состоянии сессии Алисы, а не в постоянной базе. После завершения сессии контекст может сброситься.
- Ответ специально ограничивается примерно 950 символами: Яндекс Диалоги допускают до 1024 символов в `response.text`.

## Если в тестере Яндекса показано `empty response`

1. Сначала открой `/api/health`: должен вернуться JSON `{"ok":true,"service":"alice-gemini-skill"}`. Если нет — проблема в deployment/домене, ещё до Gemini.
2. Убедись, что webhook в Яндекс Диалогах оканчивается на `/api/alice`.
3. На первом запуске убери `ALICE_SKILL_ID` из Environment Variables, сохрани и сделай Redeploy. Несовпадение ID больше не возвращает HTTP 403, но переменную лучше добавить только после проверки основного потока.
4. Проверь `GEMINI_API_KEY` в Vercel и сделай Redeploy после его добавления. На фразу «привет» навык должен отвечать без запроса Gemini; на другие вопросы проверь **Vercel → Logs**.

## Возможные следующие улучшения

- настроить системную инструкцию под конкретного персонажа или тему;

- при необходимости постоянной памяти подключить внешнюю базу данных.
