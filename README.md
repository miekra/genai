# Навык Алисы с Gemini на Vercel

Минимальный serverless-проект: webhook Яндекс Диалогов → Gemini API → ответ Алисе. Без базы данных и дополнительных npm-зависимостей. История последних четырёх обменов хранится в `session_state` навыка. Файл `vercel.json` явно назначает Node.js runtime для обоих endpoint, чтобы Vercel не пытался собирать проект как Python-приложение.

## Что понадобится

- аккаунт Google AI Studio и Gemini API key: https://aistudio.google.com/apikey
- аккаунт GitHub
- аккаунт Vercel: https://vercel.com/
- доступ к консоли Яндекс Диалогов: https://dialogs.yandex.ru/development

## Развёртывание на Vercel

1. Создай пустой репозиторий GitHub и загрузи в него все файлы этого проекта.
2. В Vercel выбери **Add New → Project**, импортируй репозиторий. В репозитории на верхнем уровне должны лежать `package.json`, `vercel.json` и папка `api/` с двумя JS-файлами (не загружай ZIP как единственный файл). Если раньше Vercel пытался запустить Python, открой **Settings → General → Build & Development Settings**: Framework Preset выбери **Other**, Root Directory укажи папку, где лежат `package.json` и `vercel.json`, а Python-specific build/output overrides удали. Затем сделай новый deploy.
3. В настройках проекта Vercel открой **Settings → Environment Variables**. Добавь:
   - `GEMINI_API_KEY` — ключ из Google AI Studio (обязателен).
   - `GEMINI_MODEL` — необязательно; по умолчанию `gemini-3.5-flash-lite`.
   - `ALICE_SKILL_ID` — необязательно на первом шаге; ниже объясняется, как включить проверку.
4. После добавления переменных сделай redeploy (новый deployment), чтобы они применились.
5. Проверь `https://ТВОЙ-ПРОЕКТ.vercel.app/api/health`. Должен прийти JSON `{"ok":true,"service":"alice-gemini-skill"}`.

## Подключение навыка в Яндекс Диалогах

1. Создай навык в консоли разработчика Яндекс Диалогов.
2. В настройке Backend выбери **Webhook URL** и укажи `https://ТВОЙ-ПРОЕКТ.vercel.app/api/alice`.
3. Сохрани настройки и перейди во вкладку тестирования. Отправь фразы вроде «Привет», «Объясни, что такое нейросеть простыми словами» и «Помнишь, о чём мы говорили?».
4. После создания навыка скопируй его `skill_id` из сведений о навыке. В Vercel добавь переменную `ALICE_SKILL_ID` с этим точным значением и сделай redeploy. Тогда endpoint будет отклонять запросы с другим `skill_id`.

## Локальная проверка

Нужен Node.js 20 или новее.

```bash
npm run check
```

Проверка доступности после deploy:

```bash
curl https://ТВОЙ-ПРОЕКТ.vercel.app/api/health
```

Webhook можно проверить примерным запросом из консоли Диалогов. Для прямого теста замени `skill_id` на фактический ID навыка, если включил `ALICE_SKILL_ID`:

```bash
curl -X POST 'https://ТВОЙ-ПРОЕКТ.vercel.app/api/alice' \
  -H 'Content-Type: application/json' \
  -d '{
    "meta": {"locale":"ru-RU"},
    "request": {"type":"SimpleUtterance","command":"Объясни квантовую физику простыми словами","original_utterance":"Объясни квантовую физику простыми словами"},
    "session": {"new":true,"message_id":0,"session_id":"test-session","skill_id":"YOUR_SKILL_ID"},
    "state": {"session":{}},
    "version":"1.0"
  }'
```

## Важные нюансы

- **Лимит Яндекс Диалогов — 4,5 секунды на весь webhook.** Вызов Gemini ограничен 3,2 секунды, чтобы оставить время на сеть и ответ Алисе. Если Gemini или холодный старт Vercel задержится, навык вернёт дружелюбное сообщение с просьбой повторить вопрос. Это ограничение платформы, а не гарантия скорости модели.
- Квоты Gemini API зависят от модели, проекта и текущих условий аккаунта; бесплатный доступ не означает безлимитное использование. Посмотри действующие квоты в Google AI Studio.
- В Vercel Hobby соблюдай условия бесплатного тарифа. Ключ Gemini хранится только в server-side Environment Variables — не добавляй его в код или публичный репозиторий.
- `ALICE_SKILL_ID` — дополнительная базовая защита от случайного/постороннего использования публичного webhook; это не полноценная криптографическая авторизация.
- История диалога хранится в состоянии сессии Алисы, а не в постоянной базе. После завершения сессии контекст может сброситься.
- Ответ специально ограничивается примерно 950 символами: Яндекс Диалоги допускают до 1024 символов в `response.text`.

## Возможные следующие улучшения

- настроить системную инструкцию под конкретного персонажа или тему;
- добавить ограничение частоты запросов и аналитику;
- вынести настройки промпта в переменные окружения;
- при необходимости постоянной памяти подключить внешнюю базу данных.
